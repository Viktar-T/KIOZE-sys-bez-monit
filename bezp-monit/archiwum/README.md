# Archiwum wykładów 2025/26

Materiały wykładowe z roku akademickiego 2025/26, przeniesione tutaj we wrześniu 2026 r., gdy wykłady zaczęto budować od nowa.

- `2025-26/wyklady-monitoring/` — seria wykładów o monitoringu (W1–W10, w tym W6–W10 w formie szkiców)
- `2025-26/wyklady-bezp/` — seria wykładów o bezpieczeństwie (W0 zadania zaliczeniowe, W1–W10, w tym W7–W10 tylko strony indeksowe)

Folder leży poza `docs/`, więc Docusaurus go nie buduje i nie publikuje. Materiały zawierają znane błędy merytoryczne (zob. przegląd kursu z września 2026 r.) i nie powinny być udostępniane studentom bez weryfikacji.
